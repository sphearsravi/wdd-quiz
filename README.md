# World Diabetes Day – Team Challenge

Two-team quiz app (Food Face-Off + Myth or Fact) for the 14 November 2026 awareness event.

Static site: `index.html` + `img/`. No build step.

- Open `index.html` locally, or deploy to Vercel (framework: Other).
- Host controls: Space = reveal/next, ← → navigate, 1 2 3 = Team 1 answers, Q W E = Team 2 answers.
- Scores are kept in the browser's localStorage; use **Reset quiz** between groups.
